# Ігротека — каталог відеоігор

Навчальний проєкт з дисципліни «Клієнтські технології Web-програмування» (СумДУ), варіант 7 «Відеоігри».

## Лабораторна робота № 2. Семантична розмітка

Сторінка `index.html` — каталог відеоігор на чистому HTML5 без стилів:

- шапка з навігацією, секція фільтрів, список карток, підвал;
- шість карток `<article>` у списку `<ul>`: обкладинка, жанр, платформи, дата виходу (`<time>`), мій час у грі (`<data>`), статус «пройдено», опис;
- адаптивні зображення (`srcset`, `sizes`, `loading`, `fetchpriority`);
- розмітка проходить W3C Nu HTML Checker без помилок і попереджень.

Обкладинки ігор взято зі Steam; вони належать правовласникам і використані лише в навчальних цілях.
